# Fly-By-Wire

## Beschreibung
Arduino-Projekt zur Simulation eines Fly-by-Wire-Systems.

## Hardware
- Arduino Uno
- Potentiometer
- Servo Motor
- LEDs

## Funktionen
- Einlesen von Steuerbefehlen
- Signalverarbeitung
- Ansteuerung von Aktoren
