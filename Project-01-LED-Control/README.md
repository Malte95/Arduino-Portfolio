# Project 01: Manual LED Circuits (Series & Parallel)

### Description
A hardware-only project demonstrating fundamental electrical circuit configurations using an Arduino Starter Kit. This setup explores how physical layouts create hardware-based logic gates by controlling the flow of electricity to an LED using multiple momentary switches.

### Engineering Concepts
* **Current Limiting:** Use of a 220-ohm resistor to protect the LED from overcurrent.
* **Circuit Continuity:** Understanding open vs. closed loop states across multiple inputs.
* **Hardware AND Logic (Series):** Sequential layout where all switches must be closed to complete the path, mimicking a logical AND gate.
* **Hardware OR Logic (Parallel):** Split-path layout where closing any individual switch completes the circuit, mimicking a logical OR gate.

### Components
* Power Source (Arduino 5V/GND Rails)
* 1x LED (e.g., Red or Green)
* 1x 220-Ohm Resistor
* 2x Push Buttons (Momentary Tactile Switches)
* Breadboard & Jumper Wires
